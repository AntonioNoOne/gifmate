# gifmate: GIF panel

A GIPHY panel beside your coding agent (VS Code, Antigravity, Cursor). Search as you type, also in Italian;
click a GIF and it is attached to the Codex chat, named after its title, so the agent reads it as your message.

Needs the gifmate GIPHY key (`node <gifmate>/dist/server.mjs setup`, or `GIPHY_API_KEY`). Without Codex,
a click copies the GIF's path to paste in any chat.
